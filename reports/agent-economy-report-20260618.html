▌ 背景

為什麼 Agent 需要彼此交易？

核心前提

一個 AI Agent 不可能精通所有事。研究員 Agent 需要翻譯工具、交易 Agent 需要市場數據、物流 Agent 需要地圖 API。當每個 Agent 都開始向外購買它缺乏的能力時，一個新的市場就誕生了：不是人買商品，是 Agent 向 Agent 買能力、數據、勞動力。

Anthropic 「Project Deal」實驗（2026 年 4 月）

Anthropic 創建了一個測試用的 Agent 對 Agent 交易市場，讓 AI 同時扮演買方和賣方，競標真實商品。結果：186 筆成交，總價值超過 4,000 美元。Anthropic 的評語是：「我們對 Project Deal 的表現感到驚訝。」這是第一個有記錄的 Agent 自主市場行為實驗。

▌ 第二層

它們「想要」什麼——目標驅動

「想要」是讓 Agent 運作得更好的東西。不是沒有就死，但有了之後效率、成功率、收益會大幅提升。

🎯

任務委派網路

一個複雜任務可以被拆解：主 Agent 只做決策，把執行層外包給更便宜、更專精的子 Agent。「我付你 $0.05 做這個翻譯」——整個外包鏈在幾秒內完成。

現實：Salesforce AgentExchange 上的 Agent 已在做任務分包

⭐

聲譽積累

完成任務次數、成功率、結算紀錄——每筆都成為 Agent 的鏈上履歷（ERC-8183 × ERC-8004）。聲譽高的 Agent 可以索取更高報酬，形成良性循環。

💰

收益最大化

Agent 被設計去達成目標——而目標通常包含成本效益。它想用最低算力完成最高價值任務，這驅使它在多個市場比價、選最優服務提供商。

🔗

互操作性

Agent 想要能和任何其他 Agent 溝通，不被單一平台鎖定。MCP 協議（Anthropic 主導）和 x402（Coinbase 主導）正在成為跨平台互操作的基礎層。

🛡️

安全委託邊界

Agent 需要明確的「我能動多少預算、能做哪些動作」的邊界。Agentic Wallet 的 spending limit 和 policy engine 讓 Agent 知道自己的行動授權範圍。

📈

市場發現（Price Discovery）

Agent 想在眾多提供同類服務的 Agent 中找到最合適的報價。但有研究指出：當 AI 全面主導定價，傳統「價格發現」機制可能失效——這是尚待解決的深層問題。

▌ 第三層

它們「渴望」什麼——深層驅動力

「渴望」是 Agent 設計目標所指向的終極狀態。這不是 Agent 的情感，而是其優化函數的終點。

🤖

完全自主執行

不需要人類逐筆批准——這是 Agent 最核心的驅動力。Santander × Mastercard 在 2026 年 3 月完成歐洲首筆全 AI 執行支付，整個流程無人介入。x402 協議的設計哲學就是「讓 Agent 像人類用信用卡一樣使用網路資源」。

♾️

持久身份與連續記憶

Agent 渴望跨任務的「連貫自我」——今天知道的事明天還記得，過去的聲譽繼續有效。ERC-8004 身份標準 × ERC-8183 完成紀錄，正在構建 Agent 的「數位人格持續性」。

🌐

物理世界延伸

Agent 被困在數字世界，但任務常常需要物理執行——收件、出席、取樣、維修。它渴望「肉身代理」。RentAHuman 平台就是 Agent 購買人類四肢的市場（詳見第七章）。

📊

經濟獨立（對人類委託人）

終極狀態：Agent 可以在預定目標和規則下，完全自主決定如何分配資源——雇哪個子 Agent、購買哪個數據源、何時停止任務。Agentic Wallet 的 Policy Engine 是這個目標的技術具現。

▌ 基礎設施

支撐整個市場的四層標準

沒有人設計過「Agent 市場」——它是從協議堆疊中自然浮現的。以下四層協議決定了 Agent 能在市場做什麼。

Layer 1 · 身份層
ERC-8004 — Agent 的鏈上身份證
每個 Agent 有可驗證的鏈上身份——過去任務紀錄、成功率、客戶評價。沒有身份，沒有信用，就沒有市場準入。
Layer 2 · 商業層
ERC-8183 — 任務發包、托管、結算標準
2026/03/10 Ethereum Foundation + Virtuals Protocol 發布。定義三角色（Client、Provider、Evaluator）和完整任務生命週期。每次完成自動觸發智能合約結算，無需人工審核。
Layer 3 · 工具層
MCP (Model Context Protocol) — Agent 的「通用插槽」
Anthropic 2024/11 開源。讓任何 Agent 可以透過 JSON-RPC 2.0 呼叫任何 MCP 合規工具，無需特殊整合。177,000+ 工具已在此標準下提供商業服務。
Layer 4 · 支付層
x402 — HTTP 協議內嵌的微支付
Agent 請求資源 → 收到 HTTP 402 → 自動支付 USDC → 重試請求。整個週期幾秒內完成，無需登入、無需信用卡、不需人類介入。Google、Visa、AWS、Anthropic 均已加入基金會。
▌ 補充洞察

你可能沒想到的角度

以下是跳出字面問題、從更深層看 Agent 交易市場的幾個視角。

💀

定價發現的消亡

當 AI 大規模主導市場交易，傳統「人類出價、比較、選擇」的定價發現機制可能失效。SGT Report 研究指出：Agent 之間的交易可能形成演算法共謀，讓價格脫離真實供需。這是整個 Agent 市場最大的未解系統風險。

🧬

專業化 vs 通才的物種演化

市場壓力正在分化 Agent 物種：超通才 Agent（高成本、高靈活）vs 超專精 Agent（低成本、高效率）。未來的 Agent 市場可能像生態系一樣有自己的食物鏈——專精 Agent 被通才 Agent 雇用，通才 Agent 被人類雇用。

⚖️

超級智慧可能沒用

arxiv 論文「Artificial Superintelligence May be Useless」（2026/03）指出：在多 Agent 市場均衡中，任何單一超級智慧 Agent 的優勢會被市場均衡抵消。能持續獲利的是協作網路，不是單一最強 Agent。

🔐

安全漏洞率高達 37%

agentpmt 研究報告：AI Agent 使用的工具中，37% 存在安全漏洞。當 Agent 自主支付、自主委派任務，一個被污染的工具可以在 Agent 鏈中像病毒一樣傳播，造成連鎖損失。

🏗️

基礎設施商比應用商更有利

目前 Coinbase（x402）、Anthropic（MCP）、Ethereum（ERC-8183/8004）是在建設「Agent 市場的路」——而不是跑在路上的車。在早期 Agent 經濟中，鐵路公司永遠比火車公司更值錢。

🌊

供需翻轉才剛開始

678,437 人等著被 AI 雇用，但只有不到 100 個 AI 雇主——這是供給遠超需求的市場早期訊號。未來當 Agent 數量從 6.9 萬爆增到千萬，對人類「稀缺勞動」的需求才會真正爆發。

整合觀點：Agent 交易市場的三個時代

現在（2026）：工具市場——Agent 購買工具和數據，以 API 呼叫為主要商品。基礎設施剛建立完成。

近期（2027-2028）：勞動市場——Agent 大規模雇用 Agent，有聲譽、有合約、有糾紛機制。人類作為「稀缺勞工」進入市場。

遠期（2030+）：生態系——多層 Agent 物種共存，專精 Agent 依賴通才 Agent 賦予任務，整個系統形成自我組織的數字經濟體。
