系統功能架構

13 項功能，全數納入本次建置

所有功能都是要做的，依交付順序分兩層：核心層先上線解決日常痛點，加值層緊接著補上讓營運更省力。

核心功能層 日常營運骨幹 優先交付 · 8 項功能 · 目標 11 月前可用
CORE 01
ICF 銷售數據匯入
上傳 ICF 匯出的 CSV，系統自動解析寫入帳務，格式異常時顯示明細不入庫，徹底取代重複 key 資料。
每日結帳核心
CORE 02
部門分帳會計
餐廳 / 吉拿棒 / 宴會廳收支獨立呈現，一鍵切換部門視角，清楚看出每條線賺賠。
財務核心
CORE 03
費用錄入與月結報表
採購、薪資、水電、雜費按部門彙整損益，月結一鍵產出且鎖定不可修改，取代手工 Excel。
財務核心
CORE 04
食材進貨與成本計算
建品項、錄採購單、庫存即時更新；BOM 食材配方結合 ICF 銷售自動推算耗用與成本。
進銷存核心
CORE 05
排班管理
三部門統一電子化班表，拖拉建立班次，系統即時計算預估人力成本，取代手寫與 Excel。
人資核心
CORE 06
出勤匯入與薪資計算
上傳 ICF 打卡 CSV，系統自動比對班表算出勤差異與薪資預估，不再肉眼核對。
人資核心
CORE 07
相關報表輸出
損益 / 出勤 / 成本等報表一鍵產出，可匯出 PDF / Excel，供店長與股東定期查閱。
財務核心
CORE 08
MUSEON AI 智能助理
基礎配置，協助查詢數據、產生月報文字摘要、回答營運問題，隨數據累積持續強化。
智慧核心
加值功能層 讓營運更省力 核心穩定後緊接導入 · 5 項功能

LINE 班表通知
班表確定後自動推播給員工，減少臨時詢問。需透過 LINE Bot（月費約 NT$200–800，依訊息量計）。

進銷存
PLUS 03
加班費自動計算
出勤差異比對班表，假日 / 加班時數自動換算費用，減少人工核算誤差。
人資
PLUS 04
第三方支付費用記錄
LINE Pay / 信用卡手續費自動拆帳入費用分錄，月損益表完整呈現金流真實成本。
財務
PLUS 05

食材消耗排行 + 毛利率最低品項自動標出，找出高成本食材與賠錢菜色。

系統定位一句話

把擺渡的帳務、成本、排班從「人工腦袋 + 散落 Excel」，轉化為可查詢、可交接、可複製的數位後台——維持 ICF 點餐不動，只補上它缺的那塊。

核心建議

維持 ICF + 新增後台，而非整套取代

這是向徐主任說明時最該重點呈現的一段——換地點本身已是風險，不該同期再換掉穩定運作的點餐系統。

面向方案 A：ICF + 後台（建議）方案 B：完整取代 ICF（不建議）
導入風險 低 — 點餐不動，後台獨立上線，互不影響 高 同期換系統又換地點，雙重混亂
上線時程 可控 — 後台 2–3 個月完成核心 11 月前完成整套極具挑戰，延遲即影響開業
員工學習成本 低 — 點餐流程不變，只有管理員學新後台 高 現場員工需 1 個月學習期
開幕期穩定度 不受影響 — ICF 久經運作 系統不穩直接衝擊來客體驗與收入
主要代價 兩套並存，ICF 銷售需定期手動匯出 CSV 數年累積資料移轉，需完整比對驗證

建議結論

採方案 A — 先建後台（記帳 + 進銷存 + 排班），維持 ICF 點餐系統不動。待新店穩定營運 6 個月後，再評估是否有換 POS 的必要性。換地點與換系統，不要在同一時間發生。

💳 第三方支付開銷說明：現行透過 ICF 收取 LINE Pay / 信用卡付款，手續費約交易金額 1.5%，每月約 NT$2,000–3,000（依刷卡量浮動），由 ICF 代扣。系統會自動把此項列入每月費用分錄，讓損益表反映真實金流成本——這是「第三方支付費用記錄」功能要接的資料來源。
範圍邊界

這次做什麼、先不做什麼

範圍講清楚，雙方對齊期待。先不做的不是做不到，是現階段 ROI 不足或定位不符。

✅ 本次建置範圍

  • 後台記帳、進銷存、排班三大模組
  • ICF 銷售 / 打卡 CSV 資料橋接
  • 部門損益分離（餐廳 / 吉拿棒 / 宴會廳）
  • 多部門帳號分開管理
  • 相關報表輸出（損益 / 出勤 / 成本）
  • 第三方支付費用自動入帳
  • MUSEON AI 助理基礎配置

❌ 此次先不做

  • 取代 ICF 點餐系統 — ICF 已穩定，換系統風險高
  • 線上掃碼點餐 / 線上訂位 — 建議 ICF 加購（已有模組）
  • 稅務試算 — 屬會計系統範疇；本系統定位記帳，稅務由會計師處理
  • 多公司整合架構 — 聚焦單一餐廳，未來擴張再評估
  • AI 數位員工 — 單店規模 ROI 不足
  • 送餐機器人 — 動線與人文禪風定位衝突
風險評估

誠實面對阻力，提前設計因應

把可能卡關的點先攤開，並準備好對策——這比假裝沒有風險更能讓業主放心。

風險機率因應方案
ICF 資料需定期手動匯出 中 設計極簡上傳流程，固定每日 / 週期匯出；格式異常即時提示，不寫入錯誤資料
BOM 配方建檔耗時 中 先建主力菜色，逐步補齊；未建配方的品項以平均成本估算，不卡上線
現場員工電腦程度不一 低 員工端只開「班表查看」唯讀權限，操作極簡；複雜功能集中在管理員後台
LINE Bot 月費 低 屬加值層，可待核心穩定後再評估啟用；NT$200–800/月，依實際訊息量計
開幕期人力吃緊無暇學新系統 低 後台由管理員主要操作，與現場出餐流程脫鉤，不佔用開幕現場人力
🌐 系統基礎費用備註（每年另計）：網址 / 主機 / SSL / LINE Bot 月費由貴司自行申辦，費用不含於本建置報價內。
