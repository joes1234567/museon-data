## 這是什麼？一句話說清楚

> **「幫 AI 找 AI 做事的媒合平台——自動配對、自動結算、全程不用人工。」**

白話版：你的 AI 助理碰到它不會做的事，自己去平台找另一個 AI 幫忙，做完自動付錢。
企業每月看報表就好，不需要人盯。

## 第一問：能做到什麼？

### 三個階段的具體成果

| 時間 | 達到什麼 | 驗收數字 |
|------|---------|---------|
| **第 1-3 個月** | 10 筆真實付費交易，確認有人要買 | 供應商 ≥20 人、買方 ≥5 家 |
| **第 4-6 個月** | 自動化平台上線，人工作業降至最低 | 月交易 ≥200 筆，達到損益平衡 |
| **第 7-12 個月** | 規模化，建立市場地位 | 月交易 ≥800 筆，月營收 NT$43 萬+ |

### 最終形態（12 個月後的樣子）

```
公司 A 的 AI 收到泰文發票
→ 自己不會泰文 OCR
→ 自動查平台：「最便宜、評分最高的泰文 OCR agent」
→ 自動下單付款，取得結果，繼續原任務
→ 全程 0 人工介入，公司月底看報表
```

### 財務可以達到什麼

| 收入來源 | 保守 | 中性 | 樂觀 |
|---------|------|------|------|
| 活躍供應商 | 50 家 | 150 家 | 400 家 |
| 月交易筆數 | 200 筆 | 800 筆 | 3,000 筆 |
| 平均每筆金額 | NT$1,500 | NT$2,000 | NT$2,500 |
| 月手續費（18%）| NT$54,000 | NT$288,000 | NT$1,350,000 |
| 訂閱 + 服務費 | NT$30,000 | NT$150,000 | NT$500,000 |
| **月營收合計** | **NT$84,000** | **NT$438,000** | **NT$1,850,000** |

月固定成本：**NT$105,000**（雲端 NT$15,000 ＋ 工程維護 NT$30,000 ＋ 客服仲裁 NT$40,000 ＋ 行銷 NT$20,000）
損益平衡：中性案第 **6-7 個月**達到（不含創辦人薪酬；含薪酬則第 8-10 個月）

| 層次 | 說明 | 估算 |

## 第二問：怎麼做？

### 階段一：驗證市場（第 1-3 個月）

**唯一目標：找到 10 筆有人真的付錢的交易**
方法：先人工，不建系統

#### 這週就做這三件事

**1. 盤點自己有什麼**
- 列出現在已有的 AI 能力清單
- 每個能力寫清楚：能做什麼任務 / 需要什麼輸入 / 產出什麼

**2. 問現有客戶**
- 聯繫 5-10 個現有合作客戶
- 問法（關鍵）：「你現在有沒有在付錢給外包做 AI 相關的事？付多少？」
- 不要問「有沒有需求」——要問「現在已經在花錢的 AI 任務」

**3. 建供應商登記表**
- 建一個 Google Form，讓開發者登記「我有什麼 agent 能力想上架」
- 發到 AI 社群（Discord、Telegram 開發者群）

#### 湊齊第一批供應商（目標 20 人）

| 招募方式 | 怎麼說 | 給什麼條件 |
|---------|-------|-----------|
| 從人脈邀請開發者 | 「你的 agent 掛著跑，我幫你找客戶，前 3 個月不抽手續費」 | 0% 手續費 3 個月 |
| 發 AI 社群招募 | 「尋找早鳥供應商，上架自己的 AI 能力，平台媒合買家」 | 早鳥認證徽章 |
| 自己上架 5 個能力 | 自己的 agent 先上，避免平台空盤 | — |

**優先招募的能力類型（企業最常需要、最容易驗收）**

| 類型 | 企業常見需求 | 容不容易驗收 |
|------|-----------|------------|
| PDF / 發票 OCR + 整理 | 財務部門每天都在做 | 容易（Schema 驗證）|
| 跨平台資料寫入 | ERP / CRM 自動填單 | 容易（日誌存證）|
| 多語言翻譯 / 合約摘要 | 有海外業務的公司 | 中（人工確認）|
| 競品監控 / 新聞摘要 | 業務和行銷部門 | 容易（截圖存證）|
| 報告 / 週報生成 | 幾乎每家公司都要 | 中（人工確認）|

#### 做成第一筆交易（全人工，不靠系統）

```
第一步：買方說「我有個任務 AI 做不到」
第二步：你從供應商清單找對應能力（人工配對）
第三步：介紹買方和供應商認識
第四步：議定費用，買方先付款到你指定帳戶
第五步：供應商執行任務
第六步：雙方確認完成（你從中協調）
第七步：扣手續費後，供應商 T+3 工作天收到款項
```

**降低買方第一次試用的障礙**
- 任務沒完成，全額退款
- 第一批客戶：平台手續費全免
- 每筆交易後提供「任務成效紀錄」，方便客戶對老闆交代

**階段一驗收標準**

| 指標 | 目標 |
|------|------|
| 付費交易筆數 | ≥ 10 筆 |
| 任務完成率 | ≥ 80% |
| 買方回購意願調查 | ≥ 7 / 10 分 |

### 階段二：建平台（第 4-6 個月）

**前提：Phase 1 達成 10 筆交易後才進入**
目標：交易不靠人工，自動完成

**要建什麼系統**

| 功能 | 說明 | 優先度 |
|------|------|-------|
| 供應商能力頁 | 像商品頁，顯示能做什麼、費率、評分 | 最優先 |
| 搜尋 + 篩選 | 依能力、價格、評分搜尋 | 最優先 |
| 點數充值 / 提領 | 買家充值，賣家提領，平台抽成 | 最優先 |
| 身份驗證 + API Key | agent 呼叫時驗證身份 | 最優先 |
| 任務追蹤 | 狀態、進度、紀錄 | 次優先 |
| 評分系統 | 完成後雙方評分 | 次優先 |
| 爭議仲裁機制 | 有爭議時的處理流程 + 退款規則 | 次優先 |

**技術架構（6-8 週可上線）**

```
使用者介面（Next.js）
        ↓
API 服務層（FastAPI / Python）
        ↓
媒合引擎 ｜ 點數系統 ｜ 驗收引擎
        ↓
資料庫（PostgreSQL）
        ↓
Agent 通訊（REST API，不綁定特定框架）
```

**商業模式（完整收入結構）**

| 收入來源 | 費率 / 金額 | 備註 |
|---------|-----------|------|
| 平台手續費 | 18% | 主要收入 |
| 供應商認證訂閱 | NT$1,500/月 | 優先曝光 + 認證標章 |
| 企業版（基本）| NT$8,000/月 | 多帳號 + 自訂 API |
| 企業版（進階）| NT$25,000/月起 | SLA + 專屬服務 |
| 企業導入服務 | NT$20,000/次 | 一次性 |

### 階段三：規模化（第 7-12 個月）

**目標：月交易額 NT$100 萬，建立行業標準地位**

- 開放 API 讓第三方 AI 工具接入平台
- 建立「Verified Agent」認證體系
- 評估新加坡、馬來西亞市場擴張
- 讓 agent 自主呼叫市場（agent-to-agent 自動交易完全成立）

## 第三問：要什麼？

### 人力

| 兼職客服 / 仲裁 | 不需要 | 1 人（10h/月）| 1 人（20h/月）|

### 資金

| 階段 | 需要多少錢 | 花在哪裡 |
|------|-----------|---------|
| Phase 1（0-3 月）| **NT$5-10 萬** | 主要是創辦人時間，工具幾乎免費 |
| Phase 2（3-6 月）| **NT$50-100 萬** | 開發 NT$30-50 萬 ＋ 雲端 NT$10 萬 ＋ 行銷 NT$20 萬 |
| Phase 3（6-12 月）| 視 Phase 2 現金流 | 中性案下 Phase 2 末期已可自籌 |

> **資金策略**：Phase 1 先用自己的錢，跑出 10 筆交易後拿這個數據找天使投資人。未驗證市場前不要借外部資金。

### 工具（Phase 1 完全免費）

| 用途 | 工具 | 費用 |
|------|------|------|
| 供應商登記 | Google Form | 免費 |
| 媒合協調 | Telegram 群組 | 免費 |
| 記帳 | Google Sheet | 免費 |
| 結算 | 銀行轉帳 | 手續費極低 |
| Phase 2 向量搜尋 | pgvector（PostgreSQL）| 開源免費 |
| Phase 2 框架 | CrewAI、LangGraph | 開源免費 |

### 法律合規（不能拖，第一筆交易前就要做）

| 項目 | 要做什麼 | 什麼時候做 |
|------|---------|-----------|
| 金流架構 | 確認是否需要「代收代付」模式（電支法合規）| **第一筆交易前** |
| 接金流工具 | 接綠界或藍新（B2B 代收代付），不能自建儲值 | **第一筆交易前** |
| 企業發票 | 企業買方需要統一發票，確認開立主體 | **第一筆交易前** |
| 供應商發票 | 提醒供應商自行處理收款發票問題 | Phase 1 開始時 |

## 常見問題直答

**Q：agent 怎麼付錢？**
A：agent 本身沒有銀行帳戶。付款主體是背後的企業或開發者，預存點數到平台，agent 執行任務時自動觸發扣款。

**Q：OpenAI / Anthropic 進來怎麼辦？**
A：他們做的是「自家生態市場」（只能用他們的 model）。這個平台是「跨廠商中立市場」（任何 agent 都能上架），方向不同，不直接競爭。他們進場反而是背書——說明 agent 市場方向對了。

**Q：供應商什麼時候拿到錢？**
A：任務驗收通過後 T+3 工作天到帳。Phase 1 手動轉帳，Phase 2 系統自動處理。

**Q：任務做壞了怎麼辦？**
A：Phase 1 全額退款保證。Phase 2 起按任務類型走驗收規則，有爭議走人工仲裁，最長 14 天解決。

**Q：台灣先跑，之後怎麼擴？**
A：台灣跑出至少 100 筆真實交易、10 家回購客戶後，帶著這份數據去談新加坡、馬來西亞的在地合作夥伴，複製同樣的 Phase 1 流程。不是靠錢砸，是靠可複製的 playbook。
